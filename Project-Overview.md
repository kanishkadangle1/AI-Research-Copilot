# Project Overview

## Problem

Researchers and students spend significant time reading multiple papers before identifying trends, gaps, and future directions.

## Solution

AI Research Copilot automates the initial research synthesis process by combining academic paper retrieval with large language model reasoning.

## Key Capabilities

* Literature review generation
* Theme extraction
* Research gap analysis
* Future scope recommendations
* Research question generation
* Paper-based conversational AI

## Architecture

User
↓
Streamlit UI
↓
arXiv API
↓
Paper Retrieval
↓
Gemini AI
↓
Research Analysis
↓
Report Generation
